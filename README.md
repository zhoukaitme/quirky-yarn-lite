# quirky-yarn-lite

Just an average Rustacean. Also a BS in CS @ Purdue University.

拿来练手的小仓库

## 用法

```bash
cat data.txt | node index.js
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 为什么写

现有的工具都太重，就想要个能管道拼接的小东西。

## 安装

```bash
git clone https://github.com/USER/quirky-yarn-lite.git
cd quirky-yarn-lite
npm install
```
